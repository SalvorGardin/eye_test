# Проверка увеличения

- 11 unit-тестов прошли, включая центральную обрезку 2× для кадров 640×480 и 480×640, один canvas для обеих моделей, переиспользование canvas, проверку границ, возврат к исходному видео 1× и освобождение памяти.
- Production-сборка для /eye-test/ прошла.
- Пакет @gigadoc/video-analysis 0.2.0 собран; отдельный пример установлен из архива и успешно собран.
- В браузерном стенде проверены выбор 2× до старта камеры, изменение 2× → 3× в API, отображение zoom в полном ответе, сброс калибровки без закрытия камеры, перенос выбранного масштаба в режим зрения, изменение до 1,5× и повторная калибровка.
- На настоящих MediaPipe-моделях с синтетическим видеопотоком увеличение 2× работает без ошибки, отсутствие лица корректно возвращает unknown. Возврат к 1× не прерывает камеру.
- Скриншот: zoom-preview.png. Качество распознавания реального лица на iPad отдельно не измерялось.
- Обновление рабочего сервера в этой итерации не выполнялось; сборка находится в dist-server/.
