# Проверка общей страницы

Дата: 2026-11-02. Изменение OpenSpec: `unified-check-page`.

- Production-сборка и проверка TypeScript прошли; 9 unit-тестов прошли.
- Строгая проверка OpenSpec прошла.
- В браузере проверены главная и API-экран. Камера не запрашивается при выборе режима.
- На браузерном стенде проверены отказ доступа и повторный запуск, отмена медленного получения камеры, все три этапа API-калибровки, сброс калибровки, потеря свежих кадров и возврат на главную.
- После отменённого запуска поздно полученная дорожка закрыта. При выходе из API закрыты дорожка и обе модели. Повторный вход начинает новую калибровку.
- Проверен переход API → главная → зрение: калибровка, тренировка, по пять ответов для каждого глаза, итоговый экран. Затем повторный вход в API без старых результатов.
- Скриншот главной: `unified-page.png`. Отсутствует горизонтальное переполнение при ширине 1280 px.

Сценарии камеры проверялись контролируемым видеопотоком и подставными результатами моделей. Точность распознавания на человеке не переоценивалась. Изменение размеров через инструмент браузера не применилось (фактическая ширина осталась 1280 px), поэтому визуальная проверка на iPad в этой итерации не подтверждена.

## Обновление: обе ориентации

Проверено через `tests/orientation.html`: настоящий viewport вложенного приложения 768×1024 и 1024×768, без перезагрузки при смене размера. В главной, API и калибровке зрения ширина документа совпадает с шириной viewport, горизонтального переполнения нет. В книжном режиме одна колонка и компактная камера внизу, в альбомном — две колонки. Поворот с работающей синтетической камерой в обоих режимах перезапускает калибровку и показывает пояснение. Сохранение ответов и отклонение незавершённого свайпа проверяет отдельный unit-тест. Все 10 тестов, сборка и строгая проверка OpenSpec прошли.

Скриншоты: `orientation-portrait.png`, `orientation-landscape.png`. Физический iPad и реальная камера в этой проверке не использовались.
