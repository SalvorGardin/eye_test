# Проверка первой версии

Дата: 2 ноября 2026, Europe/Moscow.

## Выполнено

- `pnpm test`: 5 тестов успешно — геометрия, стороны глаз, неизвестное состояние, свежесть данных, последовательная калибровка, четыре свайпа, отклонение коротких/диагональных жестов, задержка паузы, замена символа, защита от повторного ответа, 10 ответов и итог.
- `pnpm build`: проверка TypeScript и production-сборка успешно. В `dist` находятся JS/CSS, модели и WASM. Тестовый стенд не включён.
- `openspec validate camera-vision-demo --strict`: успешно.
- Локальный браузер: проверены стартовый экран и компоновка 768×1024, 1024×768, 390×844; на узком экране горизонтальной прокрутки нет.
- Тестовый стенд с canvas-видео и синтетическими ориентирами: отказ доступа → повторный запуск; все три этапа калибровки; реальный жест вправо в обучении; жест вниз и клавиатурные ответы в тесте; отведение взгляда → блокировка → другое направление того же размера без изменения номера попытки.
- Поворот 768×1024 → 1024×768: повторная калибровка, после неё сохранён ранее принятый ответ (символ 2 из 5).
- Замерший canvas-поток: неизвестные индикаторы и блокировка теста с сообщением об отсутствии свежих кадров. В процессе исправлен контроль свежести: использован requestVideoFrameCallback вместо одного лишь currentTime.
- Полный прогон: правый глаз 5/5, левый 4/5 с одним «Не различаю». После итогов тестовый счётчик подтвердил остановку одной видеодорожки и закрытие двух моделей.
- Настоящие MediaPipe-модели загрузились с локальными WASM и выполнили inference на пустом canvas-видео. Интерфейс корректно просил расположить лицо; исключений приложения не было. Служебные предупреждения MediaPipe о графическом контексте/проекции и INFO о XNNPACK не означали отказ модели.
- Принудительное событие завершения потока: камера остановлена, показано сообщение с повторным запуском.

## Не подтверждено автоматически

Распознавание реального человека, ладони и взгляда, скорость/нагрев на физическом iPad, поведение Safari при блокировке устройства и разрешения камеры на iPad. Нужно пройти ручной сценарий из README по HTTPS. Проверки с подменёнными ориентирами подтверждают логику приложения, а не точность MediaPipe.

В старом браузере без requestVideoFrameCallback используется менее надёжный fallback по currentTime; предпочтителен актуальный Safari. Приложение не измеряет расстояние до лица и медицинскую остроту зрения.
