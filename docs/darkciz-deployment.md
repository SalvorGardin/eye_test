## Завершение установки

На своём компьютере:

```sh
ssh -t orbita-server
```

На сервере после входа:

```sh
cd /home/pulse_user/eye-test-upload-adgN62Fd/darkciz-eye-test
sudo bash ./install.sh
```

Установщик `scripts/install-darkciz.sh` предназначен для первой установки. Он проверяет ожидаемый блок домена, сохраняет резервную копию Caddyfile, валидирует новый файл, устанавливает статические файлы в `/var/www/eye-test`, добавляет отдельный маршрут и запускает/перезагружает Caddy. Остальные адреса продолжают направляться в существующее приложение. При изменённой конфигурации или существующем каталоге назначения установка останавливается. При неудаче запуска прежний Caddyfile восстанавливается, файлы демо остаются для диагностики.

Если проверка или запуск Caddy не пройдут:

```sh
sudo journalctl -u caddy -n 80 --no-pager
```

Уже существующая неисправность Caddy может потребовать отдельного исправления; установщик её причину не угадывает.

После установки проверить:

- `https://darkciz.ru/` — основной сайт;
- `https://darkciz.ru/eye-test` — перенаправление со слешем;
- `https://darkciz.ru/eye-test/` — главная демо;
- оба режима и доступ к камере на iPad через HTTPS.

Маршрутизация основана на [handle_path Caddy](https://caddyserver.com/docs/caddyfile/directives/handle_path): префикс удаляется перед чтением файлов. Несуществующие файлы дают 404, а не HTML вместо WASM. GitHub Pages workflow остаётся доступен как отдельный вариант публикации.
