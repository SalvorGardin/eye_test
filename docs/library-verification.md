# Проверка переносимого модуля

Дата: 2 ноября 2026, Europe/Moscow.

- Анализ и калибровка находятся в `src/video-analysis`, демо импортирует тот же публичный модуль.
- `pnpm test`: 9 тестов успешно. Помимо прежней логики проверены на публичном API загрузка по заданному URL, GPU → CPU, закрытие частично созданной модели при ошибке, монотонность времени, неготовое видео, повторное закрытие, анализ после закрытия и независимость экземпляров.
- `pnpm build`: демо собирается с проверкой TypeScript.
- `pnpm package:library`: создан `artifacts/gigadoc-video-analysis-0.1.0.tgz` с ESM, декларациями, моделями, WASM, README и примером. Пакет не публиковался.
- Отдельный `examples/integration` устанавливает именно архив как `@gigadoc/video-analysis`; в его коде нет относительных ссылок на `src` демо.
- `pnpm --dir examples/integration build`: успешно, включая проверку деклараций без `skipLibCheck` и копирование ресурсов из установленного пакета.
- Импорт установленного пакета и subpath `/core` в Node без DOM: успешно, загрузка моделей при импорте не запускается.
- В браузере по `http://localhost:5174` отдельный пример загрузил настоящие модели из `/video-analysis`, обработал canvas-видеопоток без лица, корректно показал неизвестные признаки. Проверены остановка и повторный запуск без исключений приложения. Служебное INFO от XNNPACK выводится MediaPipe через error-канал консоли, но не является ошибкой выполнения.
- В исходном демо повторно пройдены три этапа калибровки, тренировка, замерший кадр с блокировкой, восстановление, 10 ответов. Получены ожидаемые итоги 5/5 справа и 0/5 слева (пять «Не различаю»). После завершения тестовый стенд подтвердил остановку одной дорожки и закрытие двух моделей.
- `openspec validate reusable-video-analysis --strict`: успешно.

Распознавание реального человека повторно не оценивалось: этот рефакторинг сохраняет алгоритм. Для нового проекта нужно корректно разместить ресурсы, показывать инструкции калибровки и обрабатывать свежесть результатов. Библиотека не владеет камерой и не останавливает чужие видеодорожки.
