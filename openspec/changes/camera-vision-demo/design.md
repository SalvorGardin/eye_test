# Design

## Context
Проект пуст, кроме установленного OpenSpec. Требования подтверждены после интервью. iPad неподвижен, расстояние 40–70 см, Safari, портретная и альбомная ориентации. См. proposal.md.

## Goals / Non-Goals
**Goals:** проверяемый локальный сценарий и явное неизвестное состояние распознавания.
**Non-Goals:** диагноз, физическая калибровка медицинской таблицы, антифрод, учётные записи и хранение видео.

## Decisions
- TypeScript + Vite и обычные HTML/CSS вместо React: мало экранов, не нужен UI-фреймворк. MediaPipe Tasks Vision — единственная runtime-зависимость.
- Отдельные чистые функции геометрии и конечный автомат теста. Камера и DOM остаются тонкими адаптерами. Проверки через встроенный node:test, без отдельного тестового фреймворка.
- Face Landmarker и Hand Landmarker работают по очереди на кадрах с ограничением частоты; локальные WASM и модели исключают отправку кадров и зависимость от CDN во время работы. GPU с fallback на CPU. CPU-нагрузка и отзывчивость проверяются на реальном iPad.
- Взгляд — эвристика положения радужек относительно век и направления головы, нормированная по калибровке. Это не полноценный eye tracking. Используются только неприкрытые открытые глаза, допускается широкий диапазон взгляда на экран.
- Прикрытие — попадание области глаза в многоугольник ладони/пальцев. Стороны анатомические, видео зеркальное только при отображении. Потеря лица не означает прикрытие.
- Начальная калибровка: устойчивый взгляд в центр около двух секунд, затем подтверждение прикрытия левого и правого глаза около секунды. Есть перезапуск и подсказки.
- Стабильность: около 500 мс до паузы и около 600 мс хороших условий до восстановления. Устаревший кадр, фон, остановка камеры немедленно блокируют ответы. Новый символ при восстановлении отличается от предыдущего.
- Свайпы через Pointer Events, один указатель, минимальное расстояние и доминирующая ось. Поддержка клавиатурных стрелок как доступный эквивалент, без кнопок направления. Кнопка «Не различаю» доступна отдельно.
- Размеры E в CSS-пикселях: 120, 96, 72, 54, 40; одинаковы для глаз, не являются медицинской шкалой. SVG с равной толщиной пяти долей вместо зависимого от шрифта символа.
- Состояние только в памяти. При повороте сохраняется принятый счёт, отменяется текущий символ и требуется полная перекалибровка. После итогов дорожки камеры закрываются.
- Реализация сначала в текущей локальной папке проекта; README содержит инструкции HTTPS для iPad. Публикация и выбор внешнего хостинга не входят в подтверждённый объём.

## Risks / Trade-offs
- Ладонь скрывает ориентиры лица → состояние «не удалось определить», подсказка скорректировать руку, без обхода проверки.
- Очки, блики, камеры разных iPad → настройка допусков в одном месте и ручная проверка, без обещаний точности.
- Взгляд на экран и в сторону близки → широкие допуски для демо; проверка поворота головы совместно с глазами.
- Safari может приостановить видеопоток → контроль свежести, повторное разрешение/запуск камеры и калибровка.
- Проверка в настольном браузере не подтверждает реальный iPad → явно отделить автоматические проверки от приёмки камеры на устройстве.
