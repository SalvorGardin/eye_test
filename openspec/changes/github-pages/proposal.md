# Proposal
## Why
Демонстрацию нужно публиковать на GitHub Pages из существующего репозитория без отдельного сервера.
## What Changes
- Сборка, тесты и публикация через GitHub Actions из main или вручную.
- Базовый путь сборки из настроек Pages, включая модели и WASM.
- Инструкция первоначального включения Pages и локальной проверки.
## Capabilities
### New Capabilities
- `pages-deployment`: публикация статической демонстрации.
### Modified Capabilities
Нет.
## Impact
Workflow, версия пакетного менеджера, документация. Публичный API анализатора не меняется. В этой задаче подготавливаются файлы; удалённая публикация не выполняется.
