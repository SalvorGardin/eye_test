## ADDED Requirements
### Requirement: Публикация Pages
Workflow SHALL проверять тесты, собирать демонстрацию с базовым путём Pages и публиковать только dist после успешной сборки.
#### Scenario: Обновление main
- **WHEN** изменения отправлены в main при включённом Pages
- **THEN** запускаются тесты и сборка, затем публикация, при ошибке публикация не выполняется.
### Requirement: Ресурсы под путём репозитория
Сборка SHALL загружать скрипты, модели и WASM из базового пути сайта.
#### Scenario: Страница проекта
- **WHEN** базовый путь равен /eye_test/
- **THEN** ресурсы запрашиваются из /eye_test/, а не из корня домена.
