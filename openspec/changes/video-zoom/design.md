## Context
При 1× MediaPipe получает исходное видео; библиотека не владеет камерой и калибровкой.
## Decisions
При zoom > 1 переиспользовать один canvas с центральным фрагментом исходного кадра. Оба детектора используют этот canvas. Размеры обновляются при повороте. Параметр по умолчанию 1, допустимы конечные значения 1–3. При смене масштаба демо сбрасывает калибровку и старое наблюдение, сохраняя ответы. Внешний потребитель сбрасывает собственную калибровку. Превью масштабируется по центру с пропорциями видео. Настройка сохраняется между режимами до перезагрузки страницы.
## Risks / Trade-offs
Цифровой зум не добавляет деталей и может обрезать ладонь; подсказка просит оставлять лицо и руку в кадре. Точность на реальном iPad требует отдельной проверки. Новая сборка не публикуется автоматически на действующем сервере.
