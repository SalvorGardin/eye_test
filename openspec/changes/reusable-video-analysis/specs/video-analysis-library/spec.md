# Spec Delta

## Purpose
Позволяет другим веб-приложениям использовать анализ взгляда и прикрытия каждого глаза без копирования экранов демонстрации и управления камерой.

## ADDED Requirements

### Requirement: Анализ переданного видео
Библиотека SHALL принимать видео и время кадра, возвращать независимые состояния взгляда и прикрытия левого и правого глаза, включая неизвестное состояние. Без калибровки направление взгляда остаётся неизвестным.
#### Scenario: Использование существующей камеры
- **WHEN** приложение передаёт своё готовое видео для анализа
- **THEN** библиотека возвращает результат, не запрашивает другую камеру и не меняет поток или интерфейс.

### Requirement: Управление ресурсами
Библиотека SHALL загружать модели по заданному расположению ресурсов, освобождать частично созданные модели при ошибке и предоставлять безопасное повторное закрытие. Анализ после закрытия явно отклоняется.
#### Scenario: Закрытие
- **WHEN** приложение закрывает анализатор дважды
- **THEN** модели освобождаются однократно, видеодорожки приложения продолжают принадлежать приложению.

### Requirement: Переносимая калибровка
Библиотека SHALL предоставлять калибровку отдельно от интерфейса с этапом, прогрессом, подсказкой, результатом и сбросом. Алгоритм анализа и калибровки SHALL оставаться тем же для демо и подключающих проектов.
#### Scenario: Повторная настройка
- **WHEN** приложение сбрасывает калибровку после изменения положения устройства
- **THEN** старый результат больше не применяется, можно пройти настройку заново.

### Requirement: Устанавливаемый пакет
Библиотека SHALL поставляться локальным пакетом с JavaScript, TypeScript-типами, моделями, WASM и примером подключения, без зависимости от интерфейса демо и переменных его сборщика.
#### Scenario: Другой проект
- **WHEN** отдельный проект устанавливает пакет, размещает ресурсы и использует документированный API
- **THEN** он собирается и загружает анализатор без исходников и CSS демонстрационного приложения.
