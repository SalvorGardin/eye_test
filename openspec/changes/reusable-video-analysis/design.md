# Design

## Context
src/vision.ts уже содержит чистые вычисления и Calibration. src/camera.ts смешивает MediaPipe с getUserMedia и import.meta.env.BASE_URL. Демо и тесты импортируют эти файлы напрямую; публичных внешних потребителей пока нет.

## Goals / Non-Goals
**Goals:** один код алгоритма для демо и пакета, простое подключение и явное владение ресурсами.
**Non-Goals:** изменение распознавания, React-компоненты, управление чужой камерой, серверный анализ, публикация npm, новая архитектура монорепозитория.

## Decisions
- Перенести vision.ts в src/video-analysis, добавить VideoAnalyzer и index.ts с публичными экспортами. Camera становится адаптером жизненного цикла браузерной камеры поверх VideoAnalyzer; main.ts использует те же Calibration и Observation.
- API: await VideoAnalyzer.create({ assetsBaseUrl }); analyze(video, timestampMs, baseline = null); close(). Калибровка отдельно: Calibration.update(observation, now), baseline, step, progress, hint, reset(). Не вводить подписки и собственный цикл, поскольку вызывающее приложение может уже иметь видеопоток и цикл обработки.
- analyze синхронный, как MediaPipe; проверяет готовность видео и монотонность времени. Время в миллисекундах performance.now, одинаковая шкала с проверкой свежести. Повторный timestamp отклоняется; неготовое видео даёт unknown. Фоновая вкладка, частота и свежесть кадров остаются обязанностью вызывающего приложения; пример показывает requestVideoFrameCallback, ограничение частоты и сброс устаревшего результата.
- assetsBaseUrl обязателен и указывает на каталог с models/ и wasm/. Пути без Vite/DOM-глобалов при импорте. MediaPipe загружается динамически только при create(), чтобы чистые вычисления и импорт пакета не требовали браузерного окружения.
- Сборка через уже установленный TypeScript с декларациями и переписыванием относительных .ts-импортов в .js; ESM с внешней фиксированной зависимостью MediaPipe. dist-library/package.json описывает @gigadoc/video-analysis; пакет включает assets/. Команда package:library создаёт локальный .tgz в artifacts/.
- Отдельный пример examples/integration устанавливает именно .tgz, копирует assets в public/video-analysis и использует публичный API. Это проверяет переносимость вместо относительных импортов исходников.

## Risks / Trade-offs
- Забытые ресурсы → пакет включает их, пример и документация дают команды копирования.
- Неизвестное состояние ошибочно принято за false → документировать true/false/null и необходимость проверки свежести.
- Ошибки переноса → существующие проверки геометрии, новые тесты жизненного цикла анализатора и сборка отдельного потребителя.
- Крупный архив из-за WASM/моделей → сохранить локальную автономную обработку; не добавлять CDN по умолчанию.
