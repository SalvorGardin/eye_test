# Proposal

## Why
Работающий анализ видео нужно подключать к другим веб-проектам без переноса интерфейса и сценария проверки зрения. Сейчас загрузка моделей привязана к камере и Vite.

## What Changes
- Отдельный устанавливаемый ESM-пакет анализа видео с типами TypeScript.
- Публичные функции анализа и калибровки, явные пути моделей и WASM.
- Демо использует тот же модуль; получение камеры и интерфейс остаются в приложении.
- Инструкция и минимальный пример подключения к другому проекту.

## Capabilities
### New Capabilities
- `video-analysis-library`: независимый API анализа видео, калибровка и переносимый пакет.
### Modified Capabilities
Нет. Существующий сценарий демо сохраняется.

## Impact
Выделение src/vision.ts и загрузки моделей из src/camera.ts. Новых runtime-зависимостей не требуется. Пакет передаётся локальным архивом, публикация в npm не выполняется. Ранее выполненный camera-vision-demo не изменяет свой объём.
