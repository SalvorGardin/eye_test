# Spec Delta
## Purpose
Даёт пользователю общий вход в демонстрацию проверки зрения и проверку API анализа видео в одном веб-приложении.
## ADDED Requirements
### Requirement: Выбор режима
Приложение SHALL начинать с выбора «Проверка API» или «Проверка зрения» без автоматического запроса камеры. Оба режима SHALL работать в той же странице и production-сборке.
#### Scenario: Вход
- **WHEN** пользователь открывает приложение
- **THEN** доступны два варианта, камера не запрашивается до явного запуска.
### Requirement: Проверка API
Приложение SHALL показывать результаты общего анализатора, состояние калибровки, запуск/остановку камеры и сброс калибровки. Устаревшие результаты SHALL отображаться как неизвестные, ошибки запуска SHALL допускать повтор.
#### Scenario: Калибровка API
- **WHEN** пользователь запускает камеру в режиме API и проходит калибровку
- **THEN** виден живой ответ анализа, без перехода к тесту зрения.
### Requirement: Смена режима
Приложение SHALL предоставлять возврат к выбору режима, останавливать камеру и отменять незавершённый запуск при возврате. Новый режим SHALL начинаться с чистого состояния.
#### Scenario: Возврат во время запуска
- **WHEN** пользователь возвращается к выбору, пока камера или модели загружаются
- **THEN** поздний результат загрузки не открывает старый экран, полученные ресурсы освобождаются.
### Requirement: Сохранение теста зрения
Выбор проверки зрения SHALL запускать существующий сценарий калибровки, тренировки, свайпов, пауз и итогов для обоих глаз.
#### Scenario: Завершение зрения
- **WHEN** пользователь проходит десять символов
- **THEN** показаны отдельные результаты, доступны повтор и возврат к выбору режима.

### Requirement: Обе ориентации
Приложение SHALL поддерживать книжную и альбомную ориентации без горизонтального переполнения. При повороте с работающей камерой оно SHALL повторять калибровку, сохранять принятые ответы и отменять незавершённый жест.
#### Scenario: Поворот во время проверки
- **WHEN** пользователь поворачивает устройство во время теста или проверки API
- **THEN** компоновка адаптируется, прежний кадр не используется, показано пояснение повторной настройки, принятые ответы сохранены.
