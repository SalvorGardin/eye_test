# Proposal
## Why
Проверка API и демонстрация зрения доступны раздельно. Нужна одна точка входа с выбором режима.
## What Changes
- Стартовая страница с двумя вариантами: проверка API и проверка зрения.
- Встроенный экран API с камерой, калибровкой и живым ответом анализатора.
- Возврат к выбору режима с остановкой камеры и очисткой текущего сценария.
## Capabilities
### New Capabilities
- `check-mode-selection`: выбор режима и безопасные переходы в одном приложении.
### Modified Capabilities
Нет. Сценарий зрения и публичный API библиотеки сохраняются.
## Impact
Изменяются основной интерфейс, стили и README. Используется существующий Camera/VideoAnalyzer; новые зависимости и отдельный сервер не нужны. Самостоятельный пример интеграции остаётся примером установки пакета.

Оба режима поддерживают книжную и альбомную ориентацию, включая поворот во время работы.
